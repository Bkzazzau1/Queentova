# Queen Tovah Cares Foundation International

Official public website for **Queen Tovah Cares Foundation International**, founded by **Princess Dr. Jessie Joseph**.

## Stack

- SvelteKit
- Svelte 5
- TypeScript
- CSS design system
- Responsive, SEO-friendly public website architecture

## Brand direction

The visual system is derived from the official Queen Tovah logo:

- Ink: `#050204`
- Deep plum: `#2B0D2F`
- Royal purple: `#48144D`
- Purple: `#64196F`
- Antique gold: `#8B6223`
- Gold: `#C9973F`
- Bright gold: `#E1BD6A`
- Champagne: `#F0DDAD`
- Ivory: `#FFFAF2`

The site should feel premium, humanitarian, international and dignified rather than like a generic NGO template.
